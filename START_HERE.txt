ФОТОПРИНТ · AI-ассистент руководителя
Как запустить на другом компьютере
=====================================

Что нужно
---------
- Windows 10/11.
- Python 3.11 или новее: https://www.python.org/downloads/
  При установке поставьте галочку "Add python.exe to PATH".
- Node.js LTS: https://nodejs.org/ — нужен для публичной HTTPS-ссылки.
- Интернет — для установки Python-зависимостей и для AI-ответов.

Быстрый запуск
--------------
1. Распакуйте архив в любую папку.
2. Дважды щёлкните START.bat.
3. Дождитесь строки "Публичная ссылка: https://...".
4. Откройте эту ссылку или отсканируйте QR из qr\jury.png.

Первый запуск может занять 1–3 минуты: устанавливаются зависимости
и скачивается клиент туннеля (если его нет в архиве).

AI-ключ
-------
В архиве НЕТ файла .env с секретами. Без ключа приложение работает,
но AI-ответы будут локальными (fallback).

Чтобы включить реальную модель:
1. Откройте .env (создаётся автоматически из .env.example).
2. Вставьте ключ в DEEPSEEK_API_KEY=...
3. Для SECRET_KEY сгенерируйте значение:
   python -c "import secrets; print(secrets.token_urlsafe(48))"
4. Перезапустите START.bat.

Модель распознавания речи
-------------------------
В полной версии архива папка models уже есть — ничего скачивать не нужно.
В lite-версии выполните один раз:
   python scripts\setup_vosk.py
Скрипт скачает vosk-model-small-ru-0.22 в папку models.

Остановка
---------
Закройте окно START.bat или выполните:
   powershell -ExecutionPolicy Bypass -File scripts\stop_demo.ps1

Проверка
--------
- Локально: http://127.0.0.1:8001/health
- Тесты: python -m pytest -q

Важно
-----
- Публичный адрес меняется при каждом перезапуске туннеля.
  Скрипт сам обновляет tools\public-url.txt и qr\jury.png.
- Ноутбук должен быть включён, пока идёт демонстрация.
- Ссылка открывает приложение под директором: это демо-режим.
- Старый QR из другого запуска не используйте — сканируйте новый.
